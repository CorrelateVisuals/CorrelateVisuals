Correlate Visuals develops high-performance simulation and visualization tools. The work centres on the GPU: simulations that run entirely in compute shaders, renderers that show them as they happen, and data modelled so its structure can be seen.

## Technical Focus

**Core technologies**
- C++ and Vulkan for cross-platform engines
- GLSL for rendering and GPU compute
- CUDA and OpenCL for parallel computation
- Python for data processing and visualization
- TouchDesigner for interactive and live visuals

**Specializations**
- GPU simulation: cellular automata and agent-based systems in compute shaders
- Real-time graphics and Vulkan engine architecture
- Interactive visuals for installations and live performance
- Knowledge modelling and data visualization

## Interests

- **Emergent systems:** from Conway's Game of Life to simulated societies whose cells produce, trade and build.
- **Scientific data made visible:** astronomical images, stellar diagrams and point clouds.
- **Software that lasts:** deterministic results, bounded memory and programs that run for years.
- **Knowledge as graphs:** structuring texts and ideas so their connections can be explored.

## Showcase: Vulpen

![Vulpen: a node's C++ in the editor, the project's graph, and the triangle it draws](assets/vulpen.png)

Vulpen is a Vulkan engine for real-time visuals and GPU compute, where programs are graphs of nodes written in C++ and GLSL. The engine places every Vulkan barrier from the graph's connections, swaps in code changes while the project runs, and can replay any session from its command log.
